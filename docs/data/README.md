# docs/data

Files here are generated by the data imports and committed so people can review them.

| File | Made by | What to do with it |
|---|---|---|
| `place-name-matches.csv` | `pnpm db:places` | Every local unit whose name in the boundary file (Open Knowledge Nepal) differs from its name in the names dataset (local-states-nepal), with how it was matched and the area ratio. If a pair looks wrong, open an issue; the import maps it by hand from then on. |
